# Support

Contact Christopher Arnold and the Splativerse project at [splativerse@googlegroups.com](mailto:splativerse@googlegroups.com).

Include your headset model, app version, file format, and what happened. A short description of the steps to reproduce the issue is helpful. Do not send private scans, personal information or sensitive diagnostic logs unless a suitable way to share them has been agreed. Messages are handled through Google Groups and may be visible to group members or others according to its settings.

You can also report a software issue in the [public GitHub issue tracker](https://github.com/ncubeeight/Splativerse-for-Meta-Quest/issues). Public issues should contain no private files or personal details.

## Getting started

Choose **Demo.ply → Enter this space** to try the included demo. Import other supported scans using the library's file picker.

- **Left stick:** move and strafe.
- **Right stick:** turn and change height.
- **Left-stick click:** save a View.
- **X:** open or close saved Views.
- **A:** return to the starting View.
- **B:** return to the library.
- **Right trigger:** select the menu item you point at.
- **Left trigger:** restore hidden controls.

Use the library's **Show hidden scans** option and restore control to bring a hidden file back into navigation. Hiding a scan does not delete it or its saved Views.

For data handling and deletion choices, read the [privacy policy]({{ '/privacy/' | relative_url }}).
